# HPA-NNN: title

Date / verdict / author / publication / exact printed page / access coverage.

## Target
Brief exact quotation, context, qualifications, claim type, defeat condition.

## Primary evidence
Exact permissible wording with surrounding argumentative sequence; work/edition/
stable reference; page verification status; interventions/variants; retrievable
private or public locator and source hash where preserved. Chronology.

## Demonstration
Target → evidence → shared and contested interpretive premises → inference →
precise conclusion. Distinguish textual assertion, logical consequence and reading.

## Objection and strongest defence
Versioned objections; positive supporting evidence for scholar; replies/revisions;
separate assessor's actual coverage; response; precise remaining issue/verdict.

## Positive reading
Local sequence, relevant parallels, opposing evidence, discriminating evidence,
remaining alternatives and limitations.

## Novelty and consequence
Queries/citation directions/sources actually inspected; existing precedent;
downstream dependence; intact parts; no-priority claim if coverage insufficient.

## Provenance and next work
Models/configuration/prompts as known; version/withdrawal history; human review
status; closure/reopening condition; source-access limits; justified next claim.
